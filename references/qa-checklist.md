# 图形质量门禁

## 逻辑正确性

- [ ] 图中的变量、约束、方向和停止条件与正文/代码一致。
- [ ] 每条箭头都有明确含义，没有暗示不存在的因果关系。
- [ ] 判断节点的所有分支都有去向，迭代能够闭合。
- [ ] 结果图数值可追溯到真实输入，单位和口径一致。
- [ ] 示意数据已明确标注，不会被误读为实测结果。
- [ ] 图支持一个明确结论，没有与正文冲突。

## 可读性与层级

- [ ] 已按论文最终插入宽度检查字号；Visio 的 `.typography.json` 为 `PASS`，标题不小于 10 pt、节点不小于 8 pt、边标签不小于 7.5 pt。
- [ ] 中文无乱码、无方框；上下标和数学符号正确。
- [ ] 标题、轴标签、刻度、图例不重叠、不截断，图外标题与结论句有独立间距。
- [ ] 坐标区内没有长段落；右侧说明栏和底部注释确有必要且不挤压主图。
- [ ] 主路径/主结果一眼可见，次要信息不抢焦点。
- [ ] 灰度打印或色觉缺陷条件下仍能区分关键系列。

## 节点、线和标签

- [ ] 节点默认透明填充；若使用白色遮罩，有明确图义和用户确认。
- [ ] 连接线先于节点绘制，箭头端点停在节点边界，不穿过节点内部。
- [ ] 节点尺寸、边框和字母比例统一，重点节点没有大到遮挡线路。
- [ ] 共享边没有虚线露出底层颜色的叠线伪影；单层/并行/分段策略与图例一致。
- [ ] 边权或数据标签无不透明填充框；如使用白色描边，填充仍为透明。
- [ ] 标签避开节点、箭头尖端、虚线交点、坐标刻度和其他标签。

## 文件与复现

- [ ] PNG 能重新打开，尺寸达到约定门槛。
- [ ] Visio 图有对应 VSDX、规格 JSON 和 `.typography.json`，且规格记录了 `page.final_width`（旧规格使用默认 6.5 英寸）。
- [ ] 代码图有对应脚本、输入文件和固定随机种子（如涉及随机过程）。
- [ ] `figure_index.json` 路径存在且图号唯一，已记录验证尺寸和输入来源。
- [ ] 未覆盖用户已有同名文件；修订使用版本号或确认覆盖。

## 论文整合

- [ ] 图题是结论性标题，不只是对象名称。
- [ ] 正文解释了读图结论、证据意义和限制。
- [ ] 图在正文首次引用之后就近出现。
- [ ] 图号、题注、正文引用和 `figure_index.json` 一致。

运行 `scripts/validate_png.py` 做文件级检查后，仍必须人工查看 PNG 和 VSDX；自动检查无法证明图的模型逻辑正确。
