# 调研记录

## 本地优秀论文抽样

本地资料库共发现 231 篇 PDF，以及约 1,700 张独立图片文件。跨 2022–2025 年抽样的论文中，稳定出现以下证据序列：

1. 原理、坐标系或几何关系示意图；
2. 分问题求解流程或最优方案求解流程；
3. 参数变化曲线、空间方案图或预测对比；
4. 误差、敏感性或方案比较。

这说明逻辑图与结果图应分工：前者解释“为什么和怎么做”，后者证明“做得怎样”。不要用一张总流程图代替所有结果证据。
