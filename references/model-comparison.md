# 数值结果图：比较口径与证据追溯

涉及机理仿真、多情景、移动域、终止事件或精度图时阅读。绘图应消费已核验的结果；不为补齐图表擅自更换方程、重跑模型或生成随机波动。

## 图前需要确认的内容

记录数据属于观测、计算还是示意；计算结果指明模型/情景、运行版本和完成状态。用于图的具体输入文件可记录SHA256，避免同名结果被重算后仍沿用旧图。

说明量的物理定义，不仅是单位字符串。例如干基含量、湿基含量与气相含湿量即使都写kg/kg，也不能未经转换放在同一差值轴上。

对照冻结共同环境、初态、物性和数值口径；若有差异，应在图注中说明，不能把输入变化全部归因于新机制。主模型与结构扩展使用稳定且不同的图例身份。

## 时间与空间对齐

- 各模型最后一行可能是不同的终止时刻。比较场分布时先按共同实际时刻匹配；比较各自终态时明确标注，不能暗示同时刻。
- 输出间隔不是求解时间步长，事件点也不一定落在常规采样网格上。显示真实终点，不向上取整为下一采样时刻。
- 移动域中区分固定物理位置、材料标签和归一化坐标。相同数组索引未必代表同一物理位置；二维扩展须说明截面。
- 域外数据用掩码/空白，并与未知缺失区分。不填零、不延长曲线、不复制边界值来补齐形状。
- 必须重采样时保留方法和范围；不要跨越真实输入跳变或域外区间插值。

## 误差与灵敏度的图义

网格误差、时间误差、模型结构差异、环境情景、随机样本分布分别命名。两方案的范围不是置信区间；没有统计依据时不画“95%置信带”。

空间收敛图应说明固定的时间设置；时间收敛图应说明固定的空间模型。独立参考解不标成官方标准答案，除非确有官方来源。

内部使用未舍入结果计算差值，最后才决定轴标签和表格位数。四位显示不证明四位精度。模型差异小于已知数值分辨率时，不用放大坐标制造确定的优劣结论。

结构变化明显时如实显示，不为“主模型足够好”的预设结论压缩纵轴、删点或选择性截取区间。比较热力图采用共同色标；确需独立色标时明确标注。

## figure_index.json 的可选追溯字段

保持已有version=1及旧路径字符串兼容。路径相对索引文件所在目录，例如paper_output/figure_index.json中的figures/example.png；输入可以用../data/results.csv。

输入和产物可写成路径字符串，或带哈希的对象：

```json
{"path": "../data/results.csv", "sha256": "该文件实际的64位SHA256十六进制摘要"}
```

这段是结构说明，摘要必须由实际文件计算，不能把占位文字当成有效校验值。

推荐按任务记录：

| 字段 | 内容 |
|---|---|
| data_kind | observed、computed或schematic |
| run_id / run_status | 计算结果的运行标识和实际状态；完成结果为completed |
| inputs | 具体数据文件及可选sha256；定量图应有实际输入 |
| png / source | 生成图片和可编辑来源；可用带sha256的对象 |
| comparison | 如为比较图，写quantity、unit、time_basis、position_basis |
| error_definition | 标注误差、区间或不确定性来自何处 |

非空间比较的position_basis可写明确的样本/群组口径或“不涉及空间”。comparison字段用于声明，不会自动证明数据已按该口径对齐。源文件哈希可防止版本漂移，但不能认证计算完成或模型真实。

```text
python scripts/validate_figure_index.py paper_output/figure_index.json
python scripts/validate_figure_index.py paper_output/figure_index.json --strict-provenance
```

普通模式兼容旧索引，对缺少追溯信息警告；严格模式要求定量输入哈希，并要求computed条目记录已完成的运行。两种模式都检查缺文件、重复图号、已声明哈希不匹配及不完整的比较口径。

PNG检查与来源检查分开。PNG像素、格式合格仍不能证明数值、单位、坐标、图注或因果解释正确；保留人工核查。
